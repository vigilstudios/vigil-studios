# New posts stack at the top

CollectionEditor now prepends new records instead of appending them. Each successive addition becomes the first post; existing records retain their relative and manually chosen order. Table/feed, saved drafts, save/publication RPCs, the public contract and Scar's renderer preserve the stored array order. Blog already lists new posts first through descending timestamps. No schema, billing or Scar app change is needed.

Validation and deployment receipts follow below. Browser acceptance uses temporary unsaved posts only and discards them without saving or publishing. Scar's full site remains Preview pending actual round-two approval.
