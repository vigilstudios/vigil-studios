# Editable print captions and category-only labels

Scar's adapter used hard-coded seed notes for existing work and the title for new work, ignoring the existing media caption. The adapter now reads the primary media caption for Portfolio and Gallery prints and carries it through curated collaboration/camera slots. An explicit blank remains blank, so titles and captions are independent and captions can be removed. Content Hub labels the primary field **Post caption**, explains blank-to-hide, and labels additional image/video captions **Media caption**.

Work cards, markers and detail labels omit the artificial ordinal prefix. Events displays as EVENTS rather than 01 / EVENTS. Gallery accessible card labels no longer assign every new entry a seed-derived 01; actual lightbox position counts and cinematic homepage navigation are retained.

Ten reviewed import captions were recovered into their original primary media fields from source 3954ad5. The operation first passed a real database rollback verification, then applied atomically through the existing service-only save/history RPC with optimistic guards and an audit event. It normalizes the already-published snapshot and independently restores the existing draft in one transaction, preserving pending draft/public separation. Only legacy empty captions are recovered; customer captions and unknown/new posts are untouched. A collection marker makes replay inert, including after a customer deliberately clears a caption. Before/after comparison proved every non-caption record field, ID, title, media and the new Engagement post caption unchanged. Revision 5 became draft 7 / published 6 through the historical saves; this did not publish any additional record or promote Scar's full website.

Validation: 112 files / 2,306 shared tests; typecheck/lint/security/build; helper preservation/idempotence; Scar typecheck and review/production builds with 23 checks in each mode. Adapter SSR regressions verify new/custom/cleared independent captions, category-only labels, homepage propagation and Gallery detail captions. The first Gallery assertion targeted the client-laid-out wall before layout; the corrected test asserts the server-rendered detail caption. Isolated desktop/phone browser checks showed a new post title A new event post, caption a night worth remembering, category EVENTS and no ordinal. No customer posts were used as visual test fixtures.

Release boundary: shared Vigil goes live after green CI. Scar changes merge only to the existing codex/scar-blog-contact review branch and update its Preview alias. Scar main/production remains at 45d4358 and review two stays pending. No schema, entitlement, billing or access changes.
