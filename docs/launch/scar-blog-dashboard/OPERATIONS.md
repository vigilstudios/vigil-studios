# Operations

Shared Blog authoring remains available to explicitly scoped Professional / Growth Sites. Owners, managers and staff can edit; tenant RLS and server authorization remain enforced. The library supports a searchable table and visual post feed. The story editor presents text, heading and photo sections with add/style/reorder/remove controls; customers never need to write storage markup. Existing drafts open in the visual editor. Uploaded photos use the existing bounded normalization/private-storage workflow and file allowance.

Migration 0038 adds `website_blog_posts.review_sample`, a default-false field unavailable through browser table writes or the author save RPC. Its constraint prohibits publishing a sample. The normal live Blog API excludes samples. `?review=samples` exposes only staff-selected sample rows for an active, eligible website in `building` status, with the same site+tenant image authorization. It returns no samples for live, suspended, paused or archived sites. This is public review content; the editor explicitly tells the customer saving changes updates that shared preview. All other drafts remain private. Signed image links expire after one hour; refresh the page to obtain fresh links.

The three existing Scar design examples were imported as actual sample drafts, using five gallery images uploaded through her authenticated staff-view editor. The pre-existing café draft's identity and creator were retained; two new system-imported drafts have no fabricated user author ID. The import guarded the website's building state, inventory count and exact draft update timestamp before writing. No published posts, real contact messages, domain purchases or approval decisions were created. The launch approval and contact automation gates remain in force.

Scar preview builds request sample review content; production builds request approved published content. Editing an article in Vigil therefore updates its next preview load without another Scar deployment. New normal drafts stay private until published and the site is live. Sample examples stay out of production and cannot use Publish. Write a new post for a real approved article.

Sidebar order is Overview, Website, Blog, Files, Requests, Domain, Subscription. Design review remains available while the associated Professional website is awaiting launch, and hides after it becomes live. Growth tools and Settings remain available independently.
