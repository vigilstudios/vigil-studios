# Express catalogue device previews

The mobile catalogue is a single viewport-height viewer after the introduction. Its industry rail and compact control row extend to both screen edges. The title and View/Buy footer remains at the bottom in either device mode, including safe-area padding. The middle grid track owns the remaining height; a ResizeObserver fits the complete 390 × 844 phone or 1200 × 700 desktop iframe into both available dimensions. Preview links and scrolling stay inside the iframe.

The frame animates width and height over 450ms when device mode changes. The iframe always scales uniformly, including during that transition. Reduced motion disables the transition. The footer sits outside the animated industry slides, so switching industries, variants or preview mode cannot slide purchase controls out of view.

While the shared creator promotion is enabled, Creator appears first with a 15% off tag. Its displayed price uses the existing canonical creator offer calculation and its Buy URL carries the published INFLUENCE code, preserving plan/period preferences. With the current $599 build amount, that displays $509.15. Other industries keep base pricing unless a valid promotion is supplied on the catalogue URL. Disabling the shared promotion restores published ordering and base pricing. No billing rules, template content, checkout calculation or database rows were changed.

Validation for the viewport correction: local typecheck and full lint passed; all 16 focused campaign/catalogue tests passed. Browser checks passed both device modes at eight host sizes from 320 to 1440 pixels, including landscape: full-width mobile rails, preview fit and aspect ratio, footer at viewport bottom, stable footer through switching, interpolated transition geometry, reduced motion, Creator-first order/tag, correct discounted amount/code and ordinary-design pricing. Browser errors: none. Hosted CI and live release receipts are recorded on the pull request.

Run `scripts/verify-express-catalogue.mjs` with Playwright installed, or set PLAYWRIGHT_MODULE to its module path. BASE_URL selects the origin and QA_OUT selects the receipt/screenshot directory. It defaults to the /express route and writes its results outside the repository.
