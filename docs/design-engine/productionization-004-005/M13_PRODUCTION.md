## Reusable contract and structure

- Usage: **page-capable**; body section with one h2, no primary navigation, hero, route or page wrapper. Its compact category bar retains the study's navigation behavior as local gallery tools.
- Content: gallery title (180 characters), compact label (60), 1–24 uniquely identified pieces; title (120), category (32), detail (700), image and explicit `contain`/`cover` for each. Up to four categories keep the compact tool bar purposeful. Odd final rows have no duplicate or invented second image.
- Media: shared intrinsic dimensions, alt, captions, focal points, responsive sources and optional mobile sources. The approved urban studio plates are explicitly contained in the fixture adapter regardless of file ratio; reusable source has no asset IDs, client colors or brand rules. No video or commerce contract is implied.
- Compatibility: ten typography profiles and finite precision/gallery/publication art directions; only typography/art section overrides. Structural variant authored and motion none are fixed. Full-bleed/document-flow metadata produces the established section-edge notice; no sticky behavior or overlay safe zone is claimed.
- Geometry: two gapless columns at every width; desktop has one viewport row below its category bar, mobile two shorter rows. Defaults to `100svh`; the host may supply `--de-viewport-height` for its available viewport (including any host navigation allowance). Lab supplies 900/1024/844 px artboard heights. A local ResizeObserver reserves the toolbar's actual height after font loading or filter-label wrapping, using unscaled `offsetHeight` in the Lab. Readable minimum rows of 280/200 px take precedence on very short screens.
- Interaction: pointer hover or keyboard focus reveals an opaque lower-half detail panel. Enter/Space or click/tap pins/closes it. Escape closes it and restores button focus when invoked inside the panel. Focusable panels permit keyboard scrolling of long details. Unique controls/panel IDs, hidden states, live counts and pressed filters expose relationships. Native focus/blur boundaries retain the original study behavior.
- Delivery: only the first two visible images load eagerly; later images load lazily with async decoding, reserved sizes and authored responsive sources. No new dependency, animation loop or scroll listener was added. M13 contributes about 2,987 minified bytes to the internal fixture bundle; this is a harness measurement, not a client-page payload guarantee. [Bundle evidence](evidence/m13-bundle.json).

No future page recipe, motion system, overlay/modal system, route architecture, commerce, AI composition or Express generation was implemented. Its viewport size hook is a host CSS input, not a speculative page engine.
