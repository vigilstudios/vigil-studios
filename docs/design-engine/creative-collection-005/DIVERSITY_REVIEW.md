## Curation result

All twelve retained for human review. M07 deliberately uses a composed wall with deterministic reading order rather than a generic masonry mechanism. M12 introduces independent comparison rather than counting another thumbnail carousel. No light/dark, two/three-column, round/square or hover-style change is counted separately. Closest pairs remain flagged for human judgment; this document does not claim that all twelve must become reusable inventory.

The common fictional brief makes comparisons easier but introduces repeated imagery and title copy. The second and third adaptations test unrelated content, type and palettes. Real model-led apparel imagery and cinematography remain a future validation gap. Prior Hero H21 already explores an expanding index; M01 should extend or share that mechanism if selected, not create duplicate production plumbing simply because it appears in a new collection.
