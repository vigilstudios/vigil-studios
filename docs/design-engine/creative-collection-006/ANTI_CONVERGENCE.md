# Anti-convergence review · Collection 006

All 66 pairs are compared below across information model/hierarchy, spatial composition, interaction, rhythm, media and service discovery. Typography is separately recorded in the main dossier. These are qualitative review observations, not creative scores or human approvals.

## Closest pairs and decisions

- **C01 / C04:** both start from named offerings. C01 exposes all deliverables in an editorial margin; C04 progressively reveals included/excluded scope. Open scanning, spatial hierarchy and expansion rhythm differ. Keep both for review.
- **C03 / C10:** both have selection. C03 is a persistent capability directory with one evidence stage; C10 is a case relationship with two simultaneous labelled plates. Its information model, media relationship and discovery path differ. Retain for review on its evidence relationship, not its selector styling.
- **C07 / C12:** both use tables on desktop. C07 maps grouped disciplines to project phases; C12 compares complete offering scopes using shared criteria. Mobile C07 selects a phase; mobile C12 selects two offerings. Organization, comparison behavior and visitor purpose differ. A flat checklist was not retained.
- **C05 / C06:** independent visitor problems versus a dependent service progression. C05 can be read out of order; C06 requires the authored sequence. Causal hierarchy, geometry and handoff rhythm differ.
- **C06 / C08:** visitor journey with named owners versus internal system dependencies with labelled interfaces. Offset stations, ownership narrative and layer diagram differ; C08 must never imply a branching graph.
- **C09 / Collection 005 Gallery Hanging:** both use unequal images, but C09's unit is a service, evidence application and detail destination. It should not be used adjacent to Gallery Hanging. Human review should decide whether the content distinction is valuable enough for independent implementation.
- **C02 / Collection 004 Manifesto Fold:** both rely on strong language. C02 binds each offering promise to its boundary in full-width bands; it is an intentionally section-only treatment. Adjacent usage would repeat the same energy and is discouraged.

No card shape, palette, column-count change, icon swap or animation is used as the primary justification for a new study. The twelve bodies have no shared card component. The selection controls in C03/C10/C11 remain deliberately simple while their information/discovery models differ. Motion is none for all studies and therefore does not manufacture distinction.
