# Production action capability audit

5 October 2026. Audited all **73 Production registrations** individually against their current executable schemas, renderers, inspection controls and structural DNA. No status, source concept or creative review was changed. Also covered all nine other runtime predecessors (82 section contracts total). This ledger is derived from the canonical registry and `SectionContract.actions`; the serializable snapshot is [inventory.json](evidence/inventory.json).

Counts: **63 primary**, **5 secondary**, **38 item**, **10 media**, **3 whole-item** systems; **8 intentionally actionless**. Existing menu, utility, source and attribution links remain independent of contextual CTA slots. A navigation classified section-primary-action still has its existing native per-destination menu capability.

## Intentionally actionless

- **Decision Ledger / S06** (`story.decision-ledger`): The principle/tension/practice ledger is a complete explanation; disclosures already reveal its rationale.
- **Manifesto Fold / S02** (`story.manifesto-fold`): The manifesto is a complete statement, with an intentionally uninterrupted ending.
- **What we make possible / C02** (`services.capability-manifesto`): A complete capability promise and its boundaries should remain an uninterrupted manifesto.
- **Discipline matrix / C07** (`services.capability-coverage`): The aligned capability matrix conveys coverage, not distinct service-page entities; its phase controls remain inspection tools.
- **A voice, in the margin / E01** (`proof.margin-voice`): One attributed voice is the evidence; existing attribution/source links suffice without a conversion CTA.
- **The credential library / E05** (`proof.credential-library`): Credential verification sources belong to each evidence disclosure; a marketing CTA would weaken the accession record.
- **People, in their own words / E06** (`proof.moving-chorus`): E06 retains its seamless continuous-motion architecture and complete accessible still view; contextual CTAs would interrupt the chorus.
- **The review reading room / E07** (`proof.review-reading-room`): Reviews remain evidence, with original source/author links and sample-selection context.

## Structural decisions

Heroes retain the authored copy lane (H09/H16), compact inspection panel (H12), image-scene copy field (HX01), and independent bottom context register (HX02). Secondary-only and neither are supported. Scene alignment stays with the scene; H12 limits action size/style to fit its compact panel. Other existing runtime Heroes H17/H18/H22/H24 and Statement Hero receive the same contract at their existing copy/baseline/bookend/joint positions while retaining review/experimental status.

Story continuations close complete dossiers, transcripts, letters and relays. Work actions follow selected captions/chapters; selector thumbnails, paired inspection controls, video playback and M13 disclosures remain buttons. Services keep destinations inside the relevant record/disclosure/evidence/recommendation. Stage and capability-layer links are optional. Commerce destinations stay in existing product records; collection headings support media and whole-entry interaction only when the supplied media has no video controls. Proof links follow complete measurement/interview narratives or the selected case/relationship; sources and permission remain separate.

Whole-item: Offering Index rows, Gallery Hanging figures, Collection Atlas entries use one stretched native anchor plus a visible label. No duplicated hidden anchor, synthetic click handler, nested link or button. Media: Open Index, Project Chapters, Contact Room, Screening Room, Photographic Promenade, Gallery Hanging, Campaign Folio, Campaign Score, Service Field Atlas, Collection Atlas. The action wraps only the principal image; selection thumbnails and video controls remain unlinked.

## Other runtime predecessors audited

Navigation Primary/Island/Contents: primary CTA plus existing menus, no secondary CTA. Statement, Front Page H17, Open Circuit H18, Between Acts H22 and Assembly H24: primary/secondary in their authored position. Feature List: optional primary continuation after the collection, no per-feature navigation. These **nine** retain their existing non-Production status. No promotion is implied by this retrofit.
